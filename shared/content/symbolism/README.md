# Sanctuary Symbolism content package

`symbolism-v1.json` is the normalized offline package imported from the legacy `app-pages2.js` Symbolism data.

It preserves 7 sanctuary furnishings, 5 offerings, and 4 priesthood records. Each record retains its description, typological meaning, location/role/frequency metadata, color accent, and Scripture references. The shared adapter emits `symbolism_furnishings`, `symbolism_offerings`, `symbolism_priesthood`, and Scripture-reference items plus `cites_scripture` relationships.

The package is local-only and remains marked `review-required` for licensing and scholarly review. The legacy Symbolism route remains available as a compatibility surface.
