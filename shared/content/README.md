# Shared content packages

Sanctuary Studies content is versioned separately from the Electron renderer. Each package is local-first, provenance-aware, and consumable by the desktop and future Flutter repositories.

## Package map

- `scripture/` — Scripture passages, cross-references, and study notes.
- `timeline/` — 24 numbered steps, preserved prelude, and 189 learning questions.
- `library/` — Local book metadata and future chapter/content packages.
- `sanctuary/` — Sanctuary models, stages, furnishings, and comparative structures.
- `symbolism/` — Furnishing, offering, priesthood, and typology content.
- `colors/` — Sacred-color meanings, uses, and Scripture references.
- `learning/` — Judgment modules, educator resources, and learning prompts.
- `provenance/` — Source paths, revisions, licensing status, and import decisions.

The package manifest identifies legacy source material without copying web/SaaS infrastructure into the offline application.
