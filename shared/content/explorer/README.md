# 3D Sanctuary Explorer and Specialized Legacy Tools

Versioned offline package for the four legacy sanctuary explorer models, their interactive zones and diagrams, and six specialized legacy tool route records. The package stores model metadata and local diagram representations; it does not introduce a browser, server, WebGL runtime, or external asset dependency.

Source files: `app-pages3.js`, `app-data.js`
