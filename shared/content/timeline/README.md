# Timeline content package

`timeline-v1.json` is a local, versioned content package for the Aaron/Jesus sanctuary ministry timeline.

- User-facing numbered steps: 24
- Preserved source prelude: 1 (source step 0, not counted)
- Learning questions: 189
- Question types: multiple-choice, fill-blank, and true-false
- Runtime dependency: none; the Electron main process reads the JSON locally
- Source and normalization details: `shared/content/provenance/timeline-v1.json`

The package is content, not UI code. The original ZIP remains a read-only reference artifact and is not copied into the application runtime.
