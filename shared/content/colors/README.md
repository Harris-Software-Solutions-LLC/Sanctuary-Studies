# Sacred Colors content package

`colors-v1.json` is the normalized offline package imported from the legacy `app-data.js` and `app-pages2.js` Sacred Colors data.

It preserves 8 colors with hex swatches, Hebrew and Greek terms, symbolism, sanctuary use, and KJV Scripture references. The shared adapter emits `sacred_color` and Scripture-reference items plus `cites_scripture` relationships.

The package is local-only and remains marked `review-required` for licensing and scholarly review. The legacy Sacred Colors route remains available as a compatibility surface.
