# Sanctuary Studies chat history

This folder contains append-only, user-visible records of Sanctuary Studies work.

Each dated record captures the request, response summary, decisions, changed files, tests, branch or commit, and archive status. These records intentionally exclude hidden chain-of-thought, credentials, access tokens, passwords, and unrelated repository material.

Copies are maintained in the E: working copy, the D: Sanctuary Studies mirror, this repository's GitHub branch, and the designated Sanctuary Studies Google Drive folder.
